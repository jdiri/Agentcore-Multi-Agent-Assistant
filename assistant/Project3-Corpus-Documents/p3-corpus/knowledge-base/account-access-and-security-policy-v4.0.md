# Account Access & Security Policy

Version: 4.0
Effective: 2025-11-01
Supersedes: 3.4
Owner: Information Security

## 1. Purpose

This policy describes how clients sign in, what protects their accounts, and what to do if they lose access or suspect fraud.

## 2. Multi-factor authentication

2.1 Multi-factor authentication (MFA) is required on every account. Clients choose an authenticator app or a text message code when they first sign in.

2.2 A device can be marked as trusted after a successful MFA sign-in. Trusted devices are not asked for a code again for **30 days**.

## 3. Failed sign-ins and lockout

3.1 After **5 failed sign-in attempts** in a row, the account is locked for **30 minutes**.

3.2 After the lock period ends, the client can try again or reset their password. Client services cannot shorten a lock period.

## 4. Password resets

4.1 Clients reset their password from the sign-in page using "Forgot password". A reset link is sent to the email address on file.

4.2 Reset links expire after **15 minutes** and can be used only once. A client who receives a reset email they did not request can disregard it; the password does not change until the link is used.

4.3 A client who no longer has access to the email address on file must call client services and complete identity verification before the email address can be changed.

## 5. What we will never ask for

5.1 The firm will never ask a client for their password, a one-time code or an MFA code by phone, email, text or chat. Anyone asking for one of these is not acting for the firm.

## 6. Suspected fraud

6.1 A client who suspects someone else has accessed their account should call client services immediately at (800) 555-0142. Suspected fraud is also accepted as a support ticket in the Account Access category, which is handled with same-business-day priority.

6.2 When fraud is reported, the firm places a temporary hold on withdrawals and profile changes until the client's identity has been re-verified.

## 7. Session timeouts

7.1 Signed-in web sessions end after 15 minutes without activity.
